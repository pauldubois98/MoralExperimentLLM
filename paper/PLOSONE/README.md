# PLOS ONE Submission

**Venue:** PLOS ONE (open-access journal, Public Library of Science)  
**Submission:** Rolling (no deadline)  
**URL:** https://journals.plos.org/plosone/

## Formatting requirements

- **Length:** No page or word limit (conciseness encouraged)
- **Format:** Single-column, double-spaced, continuous line numbering; DOC/DOCX/RTF or PDF (LaTeX)
- **Abstract:** 300 words maximum; no citations or abbreviations; describe objectives, methods, results, significance
- **Non-technical summary:** 150–200 words, first-person, separate from abstract (required)
- **Required sections:** Title → Abstract → Introduction → Materials and Methods → Results → Discussion → (optional Conclusions) → Acknowledgments → References
- **References:** Vancouver style (numbered [1], [2], ...; first 6 authors then "et al.")
- **Figures:** TIFF or EPS, 300–600 dpi, RGB/grayscale, max 10 MB each
- **Data availability:** All data must be in a public repository with DOI/accession number
- **Not anonymous:** Author names included

## Key constraints applied to article.md

- Author name retained (PLOS ONE is not double-blind)
- "Methods" renamed to "Materials and Methods"
- Abstract rewritten to ≤300 words with no citations
- Non-technical summary added
- Vancouver numbered references [1], [2], ...
- Data availability statement added
- Ethics statement added (no human participants, so brief)

## To submit

1. Prepare manuscript as DOCX (preferred) or PDF
2. Submit via Editorial Manager: https://www.editorialmanager.com/pone/
3. Upload figures separately as TIFF files at 300+ dpi
4. Complete PLOS ONE submission checklist
