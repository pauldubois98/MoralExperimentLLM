# AIES 2026 Submission

Conference: https://www.aies-conference.com/2026/
Call for papers: https://www.aies-conference.com/2026/call-for-papers/
Abstract and Submission website: https://easychair.org/conferences/?conf=aies26

**Venue:** 9th AAAI/ACM Conference on AI, Ethics, and Society  
**Dates:** October 12–14, 2026, Malmö, Sweden  
**Deadlines:** Abstract May 14 / Full paper May 21, 2026

## Formatting requirements

- **Page limit:** 10 pages (content + figures) + unlimited references + 1 optional page for ethical/positionality statements
- **Format:** 2-column AAAI style, doubly anonymized
- **Template:** Download AAAI-2026 Author Kit at https://aaai.org/authorkit26-1/
- **Submission:** PDF via EasyChair

## Key constraints applied to article.md

- Author name removed (double-blind)
- Ethical considerations section added (optional +1 page)
- References formatted in AAAI style (author-year keys → numbered would be needed in LaTeX)
- All identifying information removed from text

## To compile

1. Download the AAAI-2026 Author Kit from https://aaai.org/authorkit26-1/
2. Use `aaai26.sty` with `aaai26.bst` for bibliography
3. Convert `article.md` content into the LaTeX template
4. Target: 10 pages in 2-column AAAI format
